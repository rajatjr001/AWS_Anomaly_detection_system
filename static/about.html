About

Built for watching weather stations closely

A small monitoring tool that checks each reading as it arrives.

Our approach

Why readings are checked as they arrive

Weather stations send a steady stream of measurements. A single unusual value can be an early sign of a sensor fault or a real event, so it is worth catching early.

AWS Anomaly Watch scores each reading with a trained model and keeps every result in a database, so the history is still there after a restart.

At a glance

Data source: automatic weather stations and manual entries.

Scoring: a trained machine learning model.

Storage: a database, not an in-memory queue.
