API reference

The dashboard uses four endpoints on the same server as this site.

Endpoints

Summary, readings, health, and ingestion

Paths are relative to your server, so the dashboard works without extra configuration.

MethodPathWhat it does
GET/api/healthReports whether the model is trained.
GET/api/summaryReturns total readings, anomalies, suspicious count, and anomaly percentage.
GET/api/readings/latest?limit=100Returns the most recent stored readings.
POST/api/ingestScores one observation, saves it, and returns its status and anomaly score.
Submit a reading

Request body for /api/ingest

Send this JSON with a POST request.

{
  "temperature": 25,
  "humidity": 60,
  "pressure": 1012,
  "rainfall": 0,
  "wind_speed": 10,
  "wind_direction": 180,
  "station_id": "manual-station",
  "source": "manual"
}

The response includes observation.status and observation.anomaly_score.
