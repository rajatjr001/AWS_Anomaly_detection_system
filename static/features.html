Features

Everything the monitor does, in one place

Scoring, storage, and live views work together so you can act on unusual readings quickly.

Anomaly scoring

Each reading is scored by a trained model and labeled normal, suspicious, or anomalous.

Saved history

Readings go to a database, so history survives restarts and page reloads.

Live trend chart

The temperature chart updates in place as new readings arrive.

Manual entry

Enter a reading by hand to test the ingestion and scoring API.

Automatic refresh

Totals and tables refresh every 5 seconds without reloading the page.

Plain JSON API

Simple endpoints for summaries, readings, health, and ingestion. See the docs page.
